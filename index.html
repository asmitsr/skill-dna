        How scores work — fully transparent

        • Activity (25%): share of repos updated in the last 90 days + recency of last push.
        • Originality (25%): share of non-fork repos. A profile that is 90% forks scores low here — this is the anti-copy signal.
        • Documentation (25%): share of repos with a description, topics and a homepage/license signal (from public metadata).
        • Popularity (25%): stars and forks, log-scaled so one viral repo cannot hide an empty profile.

        Limitations, stated honestly: Skill DNA cannot see private work, code quality inside files, tests, or teamwork. It proves public, verifiable activity — it does not claim to measure talent perfectly. Language bytes come from GitHub’s language endpoint for the top repos.

        How BYOK works — in plain words

        Step 1: You create a key on the provider’s own official website (GitHub, Google AI Studio, Groq, OpenAI). Step 2: You paste it here. Step 3: Your browser calls that provider directly. Skill DNA has no server, so your key never passes through us, is never logged, and is never shared with anyone else. This is exactly how professional tools like ChatGPT’s API playground, Postman and Vercel’s BYOK integrations work — the user brings the key, the tool just uses it.

        Tip for website owners: if you deploy Skill DNA for others, each visitor uses their own key. You do not need to buy or share one master key, and you are not responsible for their usage or billing.

        ⚙️ API Keys — Bring Your Own Key

        Add your own official third-party API keys once, then anyone using this site on this device can run it with their own keys. Keys are masked, testable, and forgettable in one click.

        Security, stated clearly: keys are stored only in this browser (if you ticked Remember), are sent only to the provider you chose, are never included in share links, printouts or recruiter summaries, and are never sent to Skill DNA — there is no Skill DNA server to send them to.
